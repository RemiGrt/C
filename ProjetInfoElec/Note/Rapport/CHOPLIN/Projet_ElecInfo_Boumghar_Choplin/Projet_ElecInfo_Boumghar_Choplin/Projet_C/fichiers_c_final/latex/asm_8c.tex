\subsection{Detailed Description}
\hypertarget{vm__codops_8h_Présentation}{}\subsection{Présentation}\label{vm__codops_8h_Présentation}
Ce programme permet d\textquotesingle{}assembler un fichier assembleur safe.\+asm en bytecode dans un fichier safe.\+bin $\ast$

Il fonctionne en deux parties \+:
\begin{DoxyItemize}
\item 1ère phase d\textquotesingle{}assemblage \+:
\begin{DoxyItemize}
\item Génère un tableau de O\+P\+\_\+\+C\+O\+DE
\item Analyse et décode les instructions
\item Construit la liste des réfèrences indéfinies
\end{DoxyItemize}
\item 2ème phase d\textquotesingle{}assemblage \+:
\begin{DoxyItemize}
\item Complète le tableau de O\+P\+\_\+\+C\+O\+DE
\item Résoud les références indéfinies
\end{DoxyItemize}
\end{DoxyItemize}\hypertarget{evm_8c_Compilation}{}\subsection{Compilation}\label{evm_8c_Compilation}

\begin{DoxyItemize}
\item Utilisation en console\+: ./asm.o
\item Commande de compilation \+: gcc \hyperlink{asm_8c}{asm.\+c} -\/o asm.\+o
\end{DoxyItemize}
